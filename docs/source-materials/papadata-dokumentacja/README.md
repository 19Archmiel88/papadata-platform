# PapaData - dokumentacja źródłowa

Ten katalog zawiera konwersję dokumentacji źródłowej dostarczonej w formacie Word do Markdown.

Dokumenty zachowują hierarchię folderów z pakietu źródłowego. Pliki w `docs/spec` pozostają wykonawczym źródłem prawdy dla implementacji, a ten pakiet jest pełnym materiałem rozszerzonym do analizy produktu, architektury, bezpieczeństwa oraz UI.
