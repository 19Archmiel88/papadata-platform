# Mapa ryzyk danych testowych

| Ryzyko | Zasada |
| --- | --- |
| Dane osobowe | Fixtures nie zawierają realnych danych klientów ani danych kontaktowych osób prywatnych. |
| Placeholder generatora | Zakazane są jawne markery generatora i teksty typu lorem. |
| Sprzeczne jednostki | Waluta, okres i źródło danych muszą być spójne w całym widoku. |
| Fałszywa pewność AI | Rekomendacje AI pokazują confidence, evidence i wymaganie zatwierdzenia człowieka. |
| Brak stanu błędu | Dla ekranów domenowych wymagane są degraded/error/no-access, gdy domena tego wymaga. |
