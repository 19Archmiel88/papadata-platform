## Indeks bezpieczeństwa platformy

### Kontrakt bezpieczeństwa

<a id="security-slo-1"></a>

| Metryka | Cel zachowany |
| --- | --- |
| RPO | <= 15 minut |
| RTO | <= 60 minut |
| P1 acknowledge | <= 15 minut |
| Containment objective | <= 60 minut |
