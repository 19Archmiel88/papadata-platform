# AI Evidence

`AIEvidence` jest wersjonowanym dowodem dla odpowiedzi AI.

Każdy fakt i istotna interpretacja wskazuje evidence. Runtime odrzuca output,
jeżeli evidence jest spoza scope albo limitations są ukryte.

Źródła Fali 5:

- `MetricSnapshot`;
- readiness;
- lineage przez Trust Drawer Fali 4;
- reconciliation;
- dataset references.
