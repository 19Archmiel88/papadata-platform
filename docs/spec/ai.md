# AI w PapaData

## Rola AI

AI jest warstwą:

- analityczną,
- operacyjną,
- decyzyjną.

Nie jest zwykłym chatem.

## Kontrakt odpowiedzi

Odpowiedź powinna rozdzielać:

- fakty,
- wnioski,
- rekomendacje,
- ograniczenia,
- brak wystarczających danych.

Powinna zawierać:

- źródła,
- zakres czasu,
- evidence,
- poziom pewności,
- wpływ jakości danych.

## Wymagane przypadki

- [ ] Odpowiedź z pełnymi danymi.
- [ ] Odpowiedź z częściowymi danymi.
- [ ] Brak danych.
- [ ] Brak uprawnień.
- [ ] Konflikt źródeł.
- [ ] Błąd providera.
- [ ] Timeout.
- [ ] Kontrolowana odmowa.

## AI Actions

- [ ] Klasy ryzyka.
- [ ] Podsumowanie wpływu.
- [ ] Approval.
- [ ] Reauthentication.
- [ ] Rewalidacja danych.
- [ ] Idempotencja.
- [ ] Audit.
- [ ] Cancellation.
- [ ] Rollback lub compensating action.
