## Required Fields

For each subprocessor record:

- legal name;
- service purpose;
- data categories;
- countries/regions;
- DPA status;
- transfer mechanism;
- security documentation link;
- owner;
- review date.

## Rule

Nie wolno oznaczyć providera jako produkcyjnie dostępnego bez zatwierdzonego
subprocessora, DPA, scope danych i runbooka incydentu.
