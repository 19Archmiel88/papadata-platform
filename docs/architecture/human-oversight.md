# Human Oversight

Poziomy:

- `READ_ONLY`;
- `HUMAN_REVIEW`;
- `SINGLE_APPROVAL`;
- `DOUBLE_APPROVAL`;
- `REAUTH_AND_APPROVAL`;
- `PROHIBITED`.

AI nie może zatwierdzić własnej propozycji. Istotne actions wymagają approval,
reauthentication, preview zakresu, preview wpływu, rewalidacji permissions i
rewalidacji targetu.
