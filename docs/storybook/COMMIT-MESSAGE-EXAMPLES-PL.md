# Przykłady commitów po polsku

Commit ma opisywać efekt, nie czynność techniczną bez kontekstu.

## Dobre przykłady

- `Doprecyzuj guardy dokumentacji i typy Storybooka`
- `Utrwal mapę zależności ekranów produkcyjnych`
- `Rozdziel walidację techniczną od akceptacji właścicielskiej`
- `Uporządkuj fixtures kampanii i centrum dowodzenia`
- `Wzmocnij kontrolę lokalnych stylów Storybooka`

## Słabe przykłady

- `fix`
- `update files`
- `changes`
- `storybook stuff`
- `final`
