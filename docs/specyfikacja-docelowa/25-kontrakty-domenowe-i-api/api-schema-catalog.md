# Kanoniczny katalog DTO i schematów API 1.0
Ten dokument zamyka wymaganie audytu F-002: każda nazwa request/response z rejestru API ma definicję w `contracts/api-schemas.ts`, `contracts/api-schemas.json` oraz `contracts/openapi-1.0.json`. Markdown nie jest jedynym źródłem kontraktu; kanoniczne źródło typów znajduje się w katalogu `contracts/`.
## Zasady kompatybilności

- `context`, `operationId` i `correlationId` są obowiązkowe.
- Commandy wymagają `idempotencyKey`, audytu i jawnego `CommandOutcome`.
- Query nie wykonuje mutacji i zwraca `DomainViewModel`.
- Callback wymaga podpisu providera.
- Job zwraca `JobStatus` albo identyfikator pracy asynchronicznej.
- Odpowiedzi błędów używają `ApiProblem` z kodem, komunikatem, polem, flagą recoverable i correlationId.
