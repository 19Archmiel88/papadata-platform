# PapaData Web

Czysty frontend PapaData utworzony od zera.

## Uruchamianie

```bash
pnpm dev:web
pnpm storybook
```

Storybook uruchamia się pod adresem
`http://localhost:6010/`.

Główne `pnpm dev` pozostaje poleceniem backendowym.

## Katalog Storybooka

- 22 główne sekcje;
- 220 numerowanych pozycji;
- klasy: reference, component, pattern,
  shell, screen i flow;
- globale: theme, locale, density i motion;
- cztery jawne viewporty;
- walidator kompletności katalogu.

Początkowe stories są oznaczone jako `draft`.
Placeholder należy zastępować rzeczywistym
komponentem produkcyjnym.
