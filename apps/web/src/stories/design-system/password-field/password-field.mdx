# Pole hasła

Pole hasła chroni wartość i zapewnia dostępny przełącznik jej widoczności.

## Podstawowe

<Canvas of={ComponentStories.Podstawowe} />

Domyślnie wartość pozostaje ukryta.

## Widoczność

<Canvas of={ComponentStories.Widocznosc} />

Przełącznik nie zmienia zapisanej wartości.

## Walidacja

<Canvas of={ComponentStories.Walidacja} />

Polityka hasła jest opisana przed wysłaniem formularza.

## Stany

<Canvas of={ComponentStories.Stany} />

Stan nieaktywny blokuje również przełącznik widoczności.

## Zasady użycia

- Używaj właściwego atrybutu autocomplete.
- Nie blokuj możliwości wklejania hasła.
- Przełącznik posiada dostępną nazwę.
- Nie pokazuj wymagań dopiero po wystąpieniu błędu.
