- use case;
- rolę AI;
- provider;
- model i model version;
- prompt version;
- retrieval policy version;
- context sources;
- MetricSnapshot versions;
- readiness;
- limitations;
- generatedAt;
- usage;
- cost;
- human oversight;
- audit reference;
- retention status.
