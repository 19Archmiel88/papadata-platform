# UI i Storybook

## Zasady UI

- interfejs premium i enterprise,
- light i dark mode,
- nasycone, ale nieneonowe kolory,
- ograniczone użycie pogrubień,
- brak nadmiaru ramek,
- brak ciężkich kart dla każdej sekcji,
- logiczna hierarchia,
- command center,
- panele kontekstowe,
- dostępność klawiaturą.

## Grupy Storybooka

- Foundations
- Design System

- Analytics
